Project Overview:
CampusCommute is a campus ride-sharing application designed to connect verified students, faculty, and staff who travel to and from campus. The system allows users to post or request rides, match with others based on routes and schedules, communicate within the app, and promote eco-friendly commuting. 

The first release aims to develop the minimal viable product which is a fully functional prototype with the main essential features to enable ride-sharing among university users.

Release Goal:
Our release goal is to develop a secure, user-friendly, and sustainable, ride-sharing application exclusively for verified members of the university community. This app aims to simplify commuting, increase affordability, enhance safety, and promote sustainability by encouraging shared rides among students, faculty, and staff on campus.

Deliver a working minimal viable product that allows:
- Verified users to register, log in, and verify university identity.
- Drivers to post rides and set pickup/drop-off locations.
- Passengers to request rides.
- The system to ensure basic safety and verification measures.

The minimal viable product will focus on core usability and safety.

Release Scope (Key Features):
1. Ride Posting and Requesting
- Core functionality for posting rides, requesting seats, approving requests, and viewing ride details.
- Related user stories: US1, US2, US11, US14
2. User Verification and Safety
- Allow users to sign up and log in securely with university credentials. Verify drivers and passengers.
- Related user stories: US3, US20, US21
3. Communications & Notifications
- Enable in-app messaging, notifications for ride requests and confirmations.
- Related user stories: US5, US15
4. Safety & Emergency Features
- Include an emergency button to alert emergency contact and emergency contact management to change emergency contact information.
- Related user stories: US8, US17
5. Payment and Rewards
- Integration of payment for rides as well as incentives such as badges.
- Related user stories: US6, US7, US18
6. User Profiles and Feedback
- Enables driver rating system, and ride history accessibility through user profile.
- Related user stories: US4, US9, US10, US12
7. Map Integration
- Gives a visual display of pickup and drop-off points on campus map.
- Related user story: US13
8. Weather Alerts
- Alerts for bad weather conditions affecting rides.
- Related user story: US19
9. Lost and Found
- Ability to report lost items after rides.
- Related user story: US16

For Sprint 1, we have decided to give priority to core ride management, and authentication features as these are essential for a minimal functioning product. This includes the first 2 Key features listed above. We will prioritize user story 20,21, user story 1, and user story 2 for our minimal viable product.
