# Definition of Done

## Standards
- Code compiles and runs without errors
- All acceptance criteria for the user stories are met
- Code has been reviewed by the entire group and approved
- Rigorous unit tests are written and pass successfully
- Code pushed and merged into the main branch
- Documentation and comments are provided in the code
- Features demonstrated successfully during the showcase video

## Final Product 
- UI matches original intention of mockups/wireframes
- Code follows our teams conventions
- All Trello tasks are in the _completed_ column
- Features tested on real datasets and user inputs
- No console errors or warnings in the frontend
